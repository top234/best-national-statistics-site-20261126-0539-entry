**NusaData** — a national statistics site for Indonesia, built as plain static files with no build step and no network requests. Six linked sections (home, population, economy, provinces, health & education, sources) present real official figures — the 2020 Population Census (270.20 million people), BPS GDP growth and inflation series, all 34 provinces of the 2020 census in a searchable, sortable table, poverty and unemployment series, HDI, stunting and schooling — every figure labelled with its source and year, and every chart drawn by the site's own canvas code. It works on a desktop and at a phone's size.

## Run it

```sh
node serve.ts            # serves app/ at http://localhost:8080
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts   # build the hand-in: copies app/ + screenshots/ and writes out/dossier.json
```
